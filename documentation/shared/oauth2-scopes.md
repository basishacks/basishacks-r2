# OAuth2 Scopes

OAuth2 scopes are defined in `shared/oauth2-scopes.ts` as the single source of truth. Adding a new scope automatically propagates to validation, API responses, and the UI picker.

## Scope Definitions

| Scope | Description | Admin Only |
|-------|-------------|------------|
| `openid` | Access basic OpenID Connect identity information | No |
| `profile` | Access user profile information (name, picture, etc.) | No |
| `email` | Access user's email address | No |
| `offline_access` | Maintain access to resources you have granted access to | No |
| `meetings.read.application` | Reads meeting applications generated by this application | No |
| `meetings.read.all` | Reads all meetings | Yes |
| `meetings.readwrite.application` | Reads and writes meeting applications generated by this application | No |
| `meetings.readwrite.all` | Reads and writes all meetings | Yes |

## ScopeMeta Interface

```typescript
interface OAuth2ScopeMeta {
  description: string
  adminOnly: boolean
}
```

## Helper Functions

### OAuth2ScopeDescriptions

A derived object mapping scope names to descriptions:

```typescript
{ openid: 'Access basic OpenID Connect identity information', ... }
```

### OAuth2ScopesList

Array of all scope names: `['openid', 'profile', 'email', ...]`

### isAdminScope

```typescript
function isAdminScope(scope: string): boolean
```

Returns `true` if the scope requires admin privileges.

### parseScopes

```typescript
function parseScopes(scopes: string | null | undefined): string[]
```

Parses a space-separated scope string into an array.

### hasScope

```typescript
function hasScope(scopes: string | null | undefined, scope: string): boolean
```

Checks if a scope string contains a specific scope.

### addScopes

```typescript
function addScopes(scopes: string | null | undefined, toAdd: string[]): string
```

Adds scopes to an existing scope string (deduplicates).

### removeScope

```typescript
function removeScope(scopes: string | null | undefined, toRemove: string): string
```

Removes a scope from a scope string.

## Adding a New Scope

To add a new scope, simply add an entry to the `OAuth2Scopes` object:

```typescript
export const OAuth2Scopes: Record<string, OAuth2ScopeMeta> = {
  // ... existing scopes
  'custom.scope': {
    description: 'Description of what this scope allows',
    adminOnly: false  // or true for admin-only scopes
  },
}
```

The new scope will automatically:
- Appear in the scope picker modal on the application detail page
- Be validated when adding scopes to an application
- Include its description in API responses
- Be subject to admin-only restrictions if `adminOnly: true`
